**The only MCP server that lets AI agents autonomously create, manage, and optimize Meta (Facebook/Instagram) and TikTok ad campaigns — no human dashboard required.**

## What It Does

Connect this MCP server to any AI agent and it can:

- **Create full campaigns** on Meta and TikTok — campaign, targeting, creative, and ad in one call
- **Control spend** — enable, pause, update budgets, or delete campaigns instantly
- **Read performance** — impressions, clicks, spend, CTR, CPM, conversions
- **Work autonomously** — no human needs to touch any ad dashboard
